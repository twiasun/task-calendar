# 任务日历 · README

一个单文件 HTML 任务日历，用来安排每日、每周和每月任务。支持跨月连续浏览、月度目标分栏、动态高度、加粗斜体、本地字体、数据本地保存以及 A4 横向打印 / 导出 PDF。无需服务器，双击打开就能用。

## 功能总览

- **三层任务填写**：每日任务、每周任务、每月任务。
- **视图灵活**：可选起始月份、显示多个月、连续滚动、合并周。
- **月度目标增强**：
  - 背景可选「横线」或「空白」
  - 分栏可选「单栏」「等分」「非等分」
  - 等分支持 1–6 栏，非等分支持自定义两栏宽比
  - 可选显示分栏竖线
  - 可选动态高度（默认一行，最多三行，超出滚动）
- **富文本**：任意输入框支持加粗、斜体。
- **本地字体**：可手动输入系统已安装的字体名，实时生效。
- **数据保存**：自动写入浏览器 `localStorage`，另有手动保存、清空本次填写、清空全部。
- **打印友好**：A4 横向、单页合并打印、自动分页、打印时隐藏工具栏。
- **零依赖**：单 HTML 文件，无需安装、无需联网、无需后端。

## 快速开始

1. 将下面的代码保存为 `task-calendar.html`。
2. 双击文件，用浏览器打开。
3. 在工具栏选择起始月份和显示月数，开始填写。
4. 填写后点击「保存数据」，或按 `Ctrl + S` / `Cmd + S`。
5. 需要纸质版时点击「打印 / 导出 PDF」。

> 提示：所有数据默认保存在当前浏览器中。换浏览器或清理缓存前，建议先导出 PDF 或手动备份。

## 界面与操作

### 视图设置

| 控件 | 说明 |
|---|---|
| 起始月份 | 选择日历从哪个月开始显示。 |
| 显示 N 个月 | 一次显示 1–24 个月。 |
| 连续滚动 | 勾选后所有月份连续排列，适合屏幕浏览；不勾选则按月分页，适合打印。 |
| 合并周 | 勾选后，每月只保留至少占用 4 天的整周，月初/月末不足 4 天的周会被过滤掉，使每页保持 4–5 周，减少无效占用。 |

### 月度目标

月度目标区位于每个月顶部，可填写整月目标或备注。

- **背景**：`横线` 方便对齐书写，`空白` 更干净。
- **分栏**：
  - `单栏`：一整块输入区。
  - `等分`：可设置 1–6 栏，每栏宽度相同。
  - `非等分`：固定两栏，可自定义宽比，例如 `1:2`、`3:1`。
- **分栏竖线**：多栏时勾选，会在栏与栏之间显示分隔线。
- **动态高度**：
  - 勾选（默认）：输入框默认一行高，内容增多时自动长高，最多三行，超出后滚动。
  - 不勾选：月度目标区固定为 26mm 高度，与早期版本一致。

### 字体与富文本

- **字体输入框**：可手动输入字体名称，例如：
  - Windows：`Microsoft YaHei`、`SimSun`、`KaiTi`、`FangSong`
  - macOS：`PingFang SC`、`STSong`、`STKaiti`
  - Linux：`Noto Sans CJK SC`、`WenQuanYi Micro Hei`
  - 下拉列表只是常见字体建议，不是限制。只要系统已安装，输入后立即生效。
  - 清空输入框可恢复默认字体。
- **加粗 / 斜体**：
  - 选中文字后按 `Ctrl + B` 加粗，`Ctrl + I` 斜体。
  - 也可点击工具栏的 `B` / `I` 按钮。
  - 格式会随数据一起保存。

### 数据管理

| 按钮 | 作用 |
|---|---|
| 保存数据 | 将当前内容写入浏览器 `localStorage`，并记录为「已保存状态」。 |
| 清空本次填写 | 丢弃未保存的修改，恢复到上次保存的状态。 |
| 清空全部 | 删除浏览器中保存的所有任务数据，不可恢复。 |
| 打印 / 导出 PDF | 调起浏览器打印窗口，可另存为 PDF。 |

- 未保存时，工具栏右侧会显示「● 有未保存的修改」。
- 关闭或刷新页面前，如果有未保存修改，浏览器会弹出提醒。

### 打印与导出

- 页面按 A4 横向排版。
- 不勾选「连续滚动」时，每个月单独分页。
- 勾选「连续滚动」时，内容连续排列，打印时自动分页。
- 打印时工具栏自动隐藏，输入框底纹保留，光标提示隐藏。
- 建议在打印前先点击「保存数据」，避免数据未写入。

## 数据存储说明

- 存储位置：浏览器 `localStorage`。
- 存储键名：`taskCalendar_v5`。
- 存储内容：
  - `daily`：每日任务，按日期键保存。
  - `weekly`：每周任务，按周起始日期保存。
  - `monthly`：每月任务，按月份键保存，多栏时以数组形式保存。
  - `layout`：月度目标布局、字体、动态高度等设置。
- 数据与浏览器和域名绑定。使用 `file://` 打开时，数据也保存在本地浏览器中。
- 换浏览器、使用无痕模式、清理浏览器数据会导致数据丢失。
- 当前版本没有导出 JSON / 备份文件功能，建议定期打印导出 PDF 或手动备份。

## 打印与分页逻辑

- 页面尺寸：A4 横向，边距 8mm。
- 每个月块在打印时尽量占满一页。
- 未勾选「合并周」：每月所有自然周都会显示，可能出现 6 周。
- 勾选「合并周」：过滤掉本月天数少于 4 天的周，使每月保持 4–5 周，页面更紧凑。
- 若勾选「连续滚动」，打印时不会强制每月分页，而是按内容流自动分页。

## 自定义与扩展

### 修改动态高度上限

搜索代码：

```js
if (lines > 3) lines = 3;
```

把 `3` 改成想要的最大行数，例如 `4` 或 `5`。

### 修改默认布局

搜索代码：

```js
const DEFAULT_LAYOUT = {
  mode: 'single',
  equalCount: 2,
  ratioA: 1,
  ratioB: 1,
  bg: 'lines',
  dynamicHeight: true,
  showColLines: false,
  fontFamily: '',
};
```

修改后，首次打开或清空全部数据时会使用新的默认值。

### 增加字体选项

在 `<datalist id="fontList">` 中继续添加：

```html
<option value="Your Font Name">显示名称</option>
```

下拉只是建议，手动输入同样有效。

### 修改打印页面尺寸

搜索：

```css
@page{size:A4 landscape;margin:8mm;}
```

可改为 `A4 portrait` 或其他纸张尺寸。

### 修改默认显示月份

搜索初始化部分：

```js
const now = new Date();
state.startYear  = now.getFullYear();
state.startMonth = now.getMonth() + 1;
```

可改为固定年份和月份。

## 浏览器兼容性

- 推荐：Chrome、Edge、Firefox、Safari 最新版。
- 使用了 `contenteditable`、`localStorage`、`document.execCommand` 等特性，现代浏览器均支持。
- 打印效果依赖浏览器打印引擎，建议使用 Chrome / Edge 导出 PDF，效果最稳定。
- 字体显示依赖系统已安装字体，未安装时会自动回退。

---

## 已知限制

- 数据仅保存在本地浏览器，不会同步到其他设备。
- 没有导出 / 导入 JSON 功能。
- 字体只能指定一个名称，不支持多字体回退列表（如需可自行扩展）。
- 富文本仅支持加粗和斜体，不支持颜色、下划线、列表等。
- 动态高度上限固定为 3 行，可按上文自行修改。
- 打印分页由浏览器控制，不同浏览器可能略有差异。
